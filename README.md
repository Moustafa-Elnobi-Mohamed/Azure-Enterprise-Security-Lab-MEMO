# 📖 Overview

This repository documents my journey of designing, securing, automating, and hardening a production-inspired Microsoft Azure environment for a fictional organization called **MEMO Foundation**.

Instead of only studying for the **SC-500** certification, this project follows a hands-on engineering approach where every certification topic is implemented in Azure, documented, secured, and—when appropriate—automated.

The objective is to simulate the responsibilities of a **Cloud Security Engineer** working in a real enterprise environment.

---

# 🎯 Project Objectives

- Build a complete Azure enterprise environment from scratch
- Implement Microsoft Entra ID identity and access management
- Secure Azure resources following Microsoft's best practices
- Learn Infrastructure as Code (Terraform)
- Automate deployments using PowerShell, Azure CLI, and GitHub Actions
- Configure Microsoft Defender for Cloud and Microsoft Sentinel
- Simulate real-world cloud security scenarios
- Document every implementation step
- Share the journey publicly through GitHub and LinkedIn

---

# 🏢 MEMO Foundation

MEMO Foundation is a fictional organization created for this project.

It represents a medium-sized enterprise migrating from an on-premises Active Directory environment to Microsoft Azure using a Zero Trust security model.

The environment will gradually evolve throughout this project to include:

- Microsoft Entra ID
- Azure Resource Groups
- Networking
- Virtual Machines
- Storage
- Key Vault
- Azure Policy
- Microsoft Defender for Cloud
- Microsoft Sentinel
- RBAC
- Conditional Access
- Privileged Identity Management (PIM)
- Identity Governance
- GitHub Actions
- Terraform
- Azure CLI
- PowerShell
